# 정책

풀문 공유 경제 생태계의 설계 결정과 그 근거를 정리했어요. 외부 개발자가 지켜야
할 것과 운영자가 약속할 것이 여기 있어요.

## 왜 읽기 전용인가요? (2026-07-12 결정)

economy-api는 nginx를 통해 `https://api.fullmoon.ink/economy/`로 인터넷에 공개돼
있어요. 과거에는 `/v1/grant`, `/v1/revoke`, `/v1/transfer`, 설정 쓰기도 노출됐어요
— 그동안은 베어러 키 하나가 곧 조폐권이었어요. 키가 새면 원장이 샜겠죠.

경제의 주인이 한 명인 이상, 인터넷에서 잔액을 움직일 수 있는 표면은 위험만
사고 편의는 사지 않아요. 그래서 쓰기 엔드포인트를 전부 제거했어요. 지금은 키가
새도 새는 건 읽기뿐이에요.

코드에도 쓰기 경로가 남아 있지 않아요: 서버 프로세스는 `wallet.js`를 import하지
않고, GET이 아닌 요청은 인증·본문 파싱 이전에 405로 끊겨요.

**지급 경로가 필요한 기능은** 운영자와 합의해서 코인브릿지 봇 안에 수급처를
만들어요. API로 우회하지 않아요.

## 3가지 철칙 (외부 통합이 지킬 것)

1. **잔액을 캐시하지 마세요.** 잔액을 바꾸는 건 여러분 프로세스가 아니에요. 캐시는
   반드시 틀려져요 — 표시 직전에 조회하세요.
2. **자체 화폐/잔액 테이블을 만들지 마세요.** 그 순간 단일 경제가 깨져요. 여러분
   DB에는 돈이 아닌 것만 남겨요(미니게임 상태, 쿨다운, 설정).
3. **숫자를 하드코딩하지 마세요.** 배수·캡은 `/v1/config`에서 읽어요(30초 캐시).
   운영자가 값을 바꾸면 여러분 UI도 같이 움직여요.

이 규칙은 [모듈 카탈로그](https://github.com/Fullmoon-OSS/fullmoon-sdk/blob/main/MODULES.md)
등록 유지 조건이기도 해요.

## 모듈 실행 경계 (악성 코드 방지)

커뮤니티 모듈 코드는 **어디서도 우리 인프라에서 실행되지 않아요**.

- 지금: 모듈 코드는 개발자 자신의 호스팅(봇 서버)이나 디스코드/마인크래프트
  클라이언트 안에서만 돌아가요. 카탈로그(`registry/modules.json`)에는 링크와
  소개 텍스트만 살아요 — 병합된 PR은 그 자체로는 어떤 코드도 실행하지 않아요.
  카탈로그 사이트도 레지스트리 문자열을 escape해서 그려요.
- 운영자의 오라클 박스는 1자 코드(코인브릿지 봇, 플러그인, economy-api,
  모듈 사이트)만 실행해요. **커뮤니티 모듈 코드를 박스에서 돌리는 건 현행
  정책상 금지**예요. 봇을 디스코드 서버에 초대하는 것도 모듈별 심사 후
  운영자가 직접 해요.

### 미래에 박스 호스팅을 하려면 (게이트)

정책을 바꿔 모듈을 박스에서 직접 호스팅하기로 하면, 아래 게이트 전부가
선행돼요 — 하나라도 빠지면 안 돼요:

1. 모듈별 전용 비특권 리눅스 사용자 + systemd 샌드박스
   (`ProtectSystem=strict`, `PrivateTmp=yes`, `NoNewPrivileges=yes`,
   `MemoryMax`/`CPUQuota`, 이그레스 제한)
2. 원장 DB 접근 기본 금지 — 정말 필요하면 read-only 역할만 별도 부여
3. 모듈별 별도 API 키 (공유 키 금지, 즉시 폐기 가능)
4. 공개 레포 소스 + 운영자 코드 리뷰 기록

### 구조적 방어 (최악의 경우 상한)

애초에 API가 읽기 전용이라, 모듈이 키를 새 터도 피해 상한은 **원장 읽기**예요.
돈을 움직일 수 없는 건 키가 아니라 설계가 보장해요.

## 키 발급·교체 절차

1. **발급** — [API 키 발급 이슈](https://github.com/Fullmoon-OSS/fullmoon-sdk/issues/new?template=key-request.yml)를
   열거나 운영진에게 직접 알려주세요. 운영자는 32자 이상 랜덤 키를
   생성해 레지스트리에 등록하고, 키 자체는 비공개 채널로 전달해요.
   ```bash
   node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"
   ```
2. **교체** — 키 유출이 의심되면 즉시 운영진에 알려주세요. 운영자가 레지스트리에서
   해당 키를 갈아끼워요. 서버 재시작 없이는 안 되므로 새 키 발급과 함께 짧은
   다운타임이 있을 수 있어요.
3. **폐기** — 서비스를 접으면 키를 레지스트리에서 제거해요.

## 레이트리밋

| 계층 | 한도 |
|---|---|
| 앱 (클라이언트별) | 기본 60req/10s예요 |
| nginx (IP별) | 10 req/s, burst 40이에요 |

정상 봇 트래픽으로는 닿을 일이 없어요. 닿았다면 폴링 루프를 돌리고 있다는 뜻이에요
— 백오프하고, 필요하면 상향을 요청해 주세요. 폴링 권장 주기는 5초 이상이에요.

## vocabulary 동기화

원장의 거래 사유 코드와 그 한글 표시명(`txLabel`), mint/burn 분류(`TX_FILTERS`)는
운영 봇이 정의해요. API 레포의 `src/vocabulary/`는 그 **동기화 사본**이에요.
정의를 바꿀 때는 봇 쪽에서 고치고 API 레포로 byte-for-byte 복사해 주세요 — 사본이
따로 놀면 대시보드 숫자가 `/경제현황`과 어긋나요.
